# Paddle / Surya adapter refinement, round 2

Authority: intent.md §8.4, user's eight-part measurement request. Same 25 PNGs and 1,378 reviewed reference lines from round 1; verify their hashes only. Never open holdout assets. Tesseract is excluded. No provider freeze, production integration, Gemini or semantic D.

The new common `museion-geometry-evidence/1` document stores the complete emitted detection/layout payload, immutable raw boxes/polygons/confidences, geometric region containment, adaptive column bands, atomic fragments with source/split links, logical lines as lists of fragment IDs, spatial hints/features, image/model/adapter provenance and content digest. Logical envelopes are derived views, never replacements for fragments. Provider-origin labels remain uninterpreted in raw payload. Normalized fields do not infer roles, heading levels, semantic parents or final TOC membership. This development schema does not silently extend the Rust production compositor contract.

Paddle: retain all layout regions and their geometric containment edges; use supported side-by-side tall region pairs as first-choice column evidence, falling back to box-based inference only when no such pair exists. Surya: infer persistent gutter bands from relative x distributions, overlapping y supports and crossing-box barriers; no fixed pixel-width cutoff. Both preserve every region and detector box even when normalization considers it noise or uncertain.

Marginal splitting: estimate modal main-text edges, gather small edge components separated by within-box ink projection valleys, require recurrent page-level lanes and vertically distributed support, split only detector-supported geometry; no OCR strings. Record the original box, split coordinate, component/valley evidence and lane. Every resulting margin fragment has its own stable ID and logical line; unconfirmed hints remain evidence, not deletion or semantic resolution.

Grouping: aligned fragments within the same spatial column may share a logical row when supported by proximity, a detected repeated-dot run, or a dense smaller-font band. Keep each fragment and source region membership. Dotted-row hints are low-level geometry cues, not a final TOC table. Small-font hints are not final apparatus roles.

## Measurement fixed before round-2 scoring

- Primary: micro-F1 on predicted logical-line envelopes, greedy one-to-one IoU>=0.30 against the **unchanged** reference logical lines. Multiple source fragments are allowed through the predicted fragment-ID group; evaluation never uses reference labels to group predictions. Report IoU>=0.50 F1, per-page F1, macro-F1, raw detector-box baseline under the same matcher, and matched-line fragment-union coverage/IoU. Envelope gains without union support are explicitly visible.
- Catastrophic omissions (diagnostic definition): >=5 consecutive unmatched reference lines, or recall<80% in a page or reference spatial column with >=5 lines. Retain every affected page/column and missing line ID. These diagnostic cutoffs are agent-defined, not a new user acceptance gate.
- Order: correct/inverted matched pairs, pooled accuracy, all-reference-pair coverage. Also within-reference-column and cross-reference-column accuracy/inverted pairs. Fewer than two eligible matches => null, never 100%.
- Column detection: geometry-only reference partition derived from the existing development leaf/column fields (left/right, otherwise the same spatial track), excluding furniture and margin lanes from body-column scoring. Report same/different-column pair accuracy, pair coverage, column-count agreement, exact partition on matched lines, and exact partition with all reference lines matched. Existing structural category fields remain candidate-unverified; column topology is visually cross-checked and the derived partition is an evaluation sidecar, not new human D Gold. Special TOC/apparatus/margin slices use existing reference fields as diagnostic tags, with that limitation stated. Adapters never receive these fields or text.
- TOC/apparatus/marginalia: reference counts, logical matches/misses, fragment support, one-to-many fragment realization, and residual split/group errors. A fragment merged with another reference line is reported as contamination; reference lines in different categories cannot become one perfect result silently.
- Two complete model+adapter passes for each finalist, same pinned models and CPU runtime as valid round 1. Raw payload equality, normalized geometry/IDs/hierarchy/hints digest equality, and metrics equality reported separately; timestamps/latency excluded from deterministic content. Initialization, per-page latency, errors and hashes recorded.
- Winner: complete two-pass candidates ranked by primary logical micro-F1, then stricter F1, then order. Report metric sensitivity and catastrophic failures; winning this development comparison does not establish production readiness.

Only synthetic contract checks and geometry inspection are used during implementation; final scoring follows the implementation snapshot. Any runtime or implementation correction after scoring must be disclosed as another revision rather than overwritten evidence.
