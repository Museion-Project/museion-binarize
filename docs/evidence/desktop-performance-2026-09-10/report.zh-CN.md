2026-09-10；对应用户关于原页预览、黑白处理范围/速度、Python 环境报错的反馈。意图基线：`intent.md` §8.37，DP1–DP4。结论：**aligned（本机范围）**。优化版已构建并通过 LaunchServices 打开；没有发布、签名、公证、云调用或新增评测语料。

## 交付

应用：`target/release/bundle/macos/Museion Binarize Local.app`。此前给出的应用是未优化的 debug 构建，这是明显耗时来源；本次交付改为 release 优化构建。旧 debug 包及此前证据未覆盖。

- 打开 PDF 默认显示原页。原页按屏幕尺寸渲染，使用 16 MiB 有界缓存；调整黑白参数不会重新渲染原页。黑白效果只在用户切换后计算，仍使用实际输出 DPI 和既有算法。缩略图串行低分辨率加载，为主预览让出队列；旧主预览任务可被新请求取消，PNG 编码移到阻塞工作池。
- 左侧提供“全部页面 / 指定页码”、如 `1-20, 35` 的页范围，以及“仅本页”。预览上方提供“跳过本页 / 恢复本页处理”，也可恢复全部跳过页。范围外、跳过页保留在完整 PDF 中，不抽页、不重排。空范围不允许保存黑白结果。
- 局部转换在共享 Rust 核心实现，复用原图像处理和 CCITT 编码。只替换选中页面的显示内容，保持原页面对象编号；未选中对象和压缩流在保存后逐个核对。选中页面经 PDFium 再渲染核对。全页选择沿用原完整转换路径。
- Python 运行时发现会检查 Homebrew 版本目录和 Framework 安装，逐个验证 `fitz`、`PIL`，使用成功解释器的绝对路径。当前机器的 Python 3.11 可用，默认 Python 3.14 缺依赖；修复无需新安装。

## 使用边界

局部输出保留原资源以确保其余页面原样，文件可能变大；全书压缩仍选“全部页面”。选中页面与既有黑白处理一样成为栅格页，原文本与交互注释不保留在这些页上。加密 PDF 的局部转换会明确拒绝，可先另存未加密副本。Python 仍是本机外部依赖，本次证明当前机器 GUI 环境可用，不表示应用已在无 Python 的其他机器独立运行。目录质量不因这次运行时修复而获得新的跨书准确率保证。

变更定位：`task.diff`、`changed-files.json`；基线 → 实现 → 测试对应 DP1 预览钩子/队列、DP2 selective_pdf/范围 UI、DP3 release 与固定页同输出测速、DP4 Runtime 探测与最小 GUI 环境目录生成。既有 OCR/Gold/云流程未改变。
