# Bundled font

`NotoSans-Regular.ttf` is Noto Sans Regular from the official Noto Fonts
repository, pinned to the downloaded bytes by SHA-256:

`b85c38ecea8a7cfb39c24e395a4007474fa5a4fc864f6ee33309eb4948d232d5`

Source: <https://github.com/notofonts/noto-fonts/raw/main/hinted/ttf/NotoSans/NotoSans-Regular.ttf>

The accompanying `OFL.txt` is the SIL Open Font License 1.1, SHA-256
`0dab92d0544f7b233403f14b84a663bdbfa746982eda629e7f4f9ffe1b036feb`.
The font is embedded at build time and no network access occurs at runtime.
