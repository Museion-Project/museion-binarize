# Test Data

This directory holds fixtures used by automated tests and (eventually)
benchmarks.

## Directories

- `synthetic/` — Programmatically generated test images/PDFs (e.g. simple
  synthetic pages with known, constructed ground truth). These carry no
  copyright concerns because they are generated, not scanned from real
  books, and are the preferred fixture type for unit and integration tests.
- `fixtures/` — Small, provenance-documented fixtures that are not
  synthetic (for example, minimal hand-authored PDFs used to test PDF
  parsing edge cases). Every file here must be accompanied by a note on its
  source and license/permission.

## Rules for adding test data

- **No copyrighted sample pages without permission.** Do not add scans of
  real book pages, including from old or public-domain editions, unless you
  hold the rights or have documented, explicit permission to include them.
- **No generated corpus uploads without documented provenance.** If a file
  did not originate in this repository (i.e. it was generated elsewhere, or
  sourced from an external dataset), document where it came from and under
  what license or permission it is included, in this file or a sibling
  `PROVENANCE.md`/comment near the fixture.
- Prefer `synthetic/` fixtures generated by a script committed to this
  repository, so the fixture itself is reproducible from source rather than
  being an opaque binary blob.

See [`CONTRIBUTING.md`](../CONTRIBUTING.md) and
[`docs/benchmarking.md`](../docs/benchmarking.md) for how this relates to
benchmark datasets, which have additional restrictions.
