## 人工 QA

新版窗口标题为 **M PDF · Dev reference QA**。若旧窗口还有未保存编辑，先在旧窗口保存；两个窗口使用不同目录，不会互相覆盖。此候选集已保留启动预标注时落盘的所有人工编辑及原始快照。

逐行对照原图，确认文字、行框和阅读顺序。⌘Return 依次核验当前行的几何和字符，并进入下一行。改动后的部分保留待确认状态；未改动的已有人工核验状态继续保留。检查完整页没有遗漏后，在页面页签勾选可见行覆盖、填写核验人、清空已解决问题，然后点击“完成 Dev reference QA”。
